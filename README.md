# TradeLang — Bài tập lớn CSE122

Website học ngoại ngữ thương mại theo ngữ cảnh (bản mô phỏng giao diện, HTML/CSS/JS thuần).

## Các trang

| Tệp | Vai trò |
|---|---|
| `index.html` | Trang chủ dành cho khách |
| `student-dashboard.html` | Bảng điều khiển sinh viên |
| `teacher-dashboard.html` | Bảng điều khiển giảng viên |
| `admin-dashboard.html` | Quản trị hệ thống |

## Cấu trúc

- `css/style.css` — toàn bộ giao diện
- `js/main.js` — xử lý tương tác

## Cách chạy

Mở `index.html` bằng trình duyệt, không cần cài đặt hay build.
